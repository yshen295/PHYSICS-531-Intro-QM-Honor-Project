# PHYSICS-531-Intro-Quantum-Mechanics-Honor-Project
Project discription: 
Analyzed the topological properties of Dirac-like Hamiltonians by determining their bulk energy eigenvalues and calculating associated topological invariants for 1D, 2D, and 3D systems.Derived the Berry curvature and quantized Chern number for a 2D gapped Dirac Hamiltonian and analytically solved for the protected, linearly dispersing chiral edge states at a mass-domain wall, demonstrating the bulk-boundary correspondence principle.
